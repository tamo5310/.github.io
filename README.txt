ずんちゃんメセカ作成フォーム

ファイル構成
- index.html : 参加者用ページ
- admin.html : 管理者用ページ
- firebase-config.js : Firebase設定を貼るファイル
- assets/meseca-template.jpeg : メセカ背景画像

使い方
1. firebase-config.js を開き、Firebase Console の Webアプリ設定を貼ります。
2. MESECA_ADMIN_PASSWORD を任意の管理パスワードに変更します。
3. GitHub Pages にアップロードします。
4. 参加者には index.html のURLを共有します。
5. 管理者は admin.html を開いて一覧確認・ダウンロード・印刷します。

注意
- Firebase設定を入れるまでは送信ボタンを押しても保存されません。
- PC上で直接 index.html を開いた状態でも画面確認はできますが、送信保存にはFirebase設定が必要です。
